# 🚀 Getting Started

To explore the projects locally:

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the repository

```bash
cd OIBSIP
```

### 3. Choose a project

For example:

```bash
cd WebDev-L2-Calculator
```

You can then open the project in your browser or VS Code depending on the project.

---

# 🔐 Running the Login Authentication System

The authentication project contains separate client and server components.

Navigate to:

```bash
cd WebDev-L2-LoginAuthentication
```

Install the required dependencies:

```bash
npm install
```

Create your environment configuration using the provided:

```text
.env.example
```

Then configure the required environment variables.

Start the backend server using the project's available npm scripts.

> Never commit real API keys, database credentials, JWT secrets, or other sensitive environment variables to GitHub.
